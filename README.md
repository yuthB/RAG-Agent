# RAG-Agent

A retrieval-augmented generation (RAG) example that loads a PDF, indexes text chunks in Pinecone, retrieves relevant chunks for a question, and generates an answer with OpenAI.

## Pipeline Stages

The program first prepares the PDF so it can search it, then uses the useful parts of the PDF to answer a question.

### Preparing the PDF

1. Read the service keys from the private `.env` file so the program can connect to OpenAI, Pinecone, and LangSmith.
2. Make sure a Pinecone index is available to store searchable information. Create it if it does not already exist.
3. Open the PDF and break its text into small, overlapping pieces. The overlap helps keep related sentences together.
4. Turn each piece of text into a numerical representation (using OpenAI embeddings) that Pinecone can compare when searching.
5. Save each text piece and its numerical representation in Pinecone, along with the text so it can be shown later.
6. Record the indexing steps in LangSmith so the run can be inspected in its project dashboard.

### Answering a Question

1. Convert the question into the same kind of numerical representation as the PDF text.
2. Ask Pinecone to find the three saved text pieces that are most related to the question.
3. Give those text pieces and the question to the chat model, asking it to answer from the PDF and say when the information is not there.
4. Print the model's answer. The chat model used here is OpenAI's `gpt-3.5-turbo`.

## Setup

1. Install Python 3.13 or newer.
2. From the project directory, create and activate a virtual environment in PowerShell:

	```powershell
	python -m venv myenv
	.\myenv\Scripts\Activate.ps1
	```

3. Install the dependencies:

	```powershell
	python -m pip install -r requirements.txt
	```

4. Create a `.env` file in the project directory with your credentials and LangSmith settings:

	```dotenv
	OPENAI_API_KEY=your-openai-api-key
	PINECONE_API_KEY=your-pinecone-api-key
	LANGSMITH_API_KEY=your-langsmith-api-key
	LANGSMITH_PROJECT=your-langsmith-project
	LANGSMITH_TRACING_V2=true
	```

	Keep `.env` private; do not commit API keys.

5. Place the source PDF at `data/BOFA_safedepositbox_disclosures.pdf`. The document is local input and is not included in this repository.

## Run

Run the script from the project directory:

```powershell
python .\agent.py
```

The script creates the `rag-agent-index` Pinecone serverless index if it does not exist, splits the PDF into overlapping chunks, generates embeddings, and upserts them into the `ns1` namespace. It then embeds the question, retrieves the three closest chunks, and prints an answer generated by `gpt-3.5-turbo`.

Edit the question in the final `rag_chain.invoke(...)` call in `agent.py` to ask something else. Running the script again reprocesses the PDF and makes embedding and chat API requests; Pinecone upserts the vectors using their existing IDs.
